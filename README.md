# 换电排程台 · 城市末端配送

- 行业：物流（末端配送换电调度）
- 技术栈：Vue3、Vite、TypeScript、Pinia、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

把原“城市末端配送模拟”的分配页补成了**换电排程台**，解决骑手低电出车、半路才找柜导致订单延误的问题。

- **资料**：车辆记余电（度）、每公里耗电、班次与温厢；换电柜记绕路里程和可约时段（含柜位数）；订单记距离、承诺时段与温区。
- **判断（派单）**：
  1. 班次已取消 → 拒派；
  2. 温区不符（常温/冷藏/冷冻）→ 拒派；
  3. 余电可覆盖订单距离 → 直送；
  4. 否则按“绕路耗电”校验能否骑到柜：柜位时段未约满、时段在班次内且不晚于承诺送达截止、余电够绕路、且换电后满电够跑订单 → 出换电方案，**换电后按满电接单**；
  5. 任一条不满足，订单留在**待处理**，原因写明缺多少公里、温区不符或柜位约满。
- **释放**：取消班次或给在途单换车，自动释放该单占用的换电柜预约、退回待处理并说明原因；订单送达后柜位也释放。
- **可追溯**：排程、拦截原因与操作日志全部保存在 localStorage，重开页面仍可见；重开班次后车辆按满电重新出勤。

## 分层

- `src/swap/types.ts`、`seed.ts`：资料模型与示例数据
- `src/swap/engine.ts`：纯函数判断层（不改状态）
- `src/swap/storage.ts`：保存层（localStorage 读写）
- `src/swap/store.ts`：Pinia 编排层（调用判断 → 落状态 → 保存）
- `src/components/*`：排程台、班次车辆、换电柜、资料建档、日志等视图
